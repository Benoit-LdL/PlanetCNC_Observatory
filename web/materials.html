Materials

The cutting values the Planing page fills in when you pick a material. Change a value and press Save on that row; add a new material in the last row. They are kept on the Pi, so every device sees the same ones.

Planing bits

The bits the Planing page offers in Bit and cut: picking one fills in its diameter. Change a value and press Save on that row; add a new bit in the last row. They are kept on the Pi, so every device sees the same ones.
